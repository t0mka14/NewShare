## Goal and rules
- Test the redesigned web (clinic / study / computer / recording words) deployed on the container
  `http://192.168.122.183:10001` plus the whole chain: web -> desktop app (config by clinic token) ->
  sessions -> upload -> record on the server. Runs are done by **Sonnet runner agents**, one at a time,
  launched by an Opus/orchestrator session. Runners find and document only: no code edits, no commits,
  no server deletions. The orchestrator saves `report.md` (runners' Write tool refuses it: they return
  the text), numbers findings in `findings.md`, and decides whether to continue. Memory note:
  `e2e-fix-workflow`.
- Success = preflight passes; every run has a `report.md` with a result for every step; every finding
  has a screenshot; the chain works (protocol built in web -> app fetches it -> sessions processed ->
  upload accepted -> recording visible and downloadable with matching ZIP SHA-256); runners edit no code;
  machine settings restored at the end. Findings themselves are not failures.
